# 稿纸尺｜标点落格与格式纠错

把申请书写进作文稿纸前，先用它在浏览器里检查一遍。工具会把电子稿转换成 A4 多页稿纸，分别生成“原样落格”和“规范建议”，标出标点跑到行首、行尾、跨格或格式不合适的风险。

## 在线使用

公开访问地址：https://lllanmei002-boop.github.io/paper-ruler-web/

## 本地使用

在 Chrome、Edge 或 Firefox 中打开 `index.html`，不需要服务器或安装依赖。

## 当前能力

- 导入 `.docx`、`.txt`、Markdown、HTML，或粘贴 PDF、网页、DOC 中的正文
- 首屏保持空白，示例内容通过“新手教学”弹窗按需载入\n- 默认 A4 纵向、20 列 × 20 行，每页 400 格
- 可切换 400 格、500 格、600 格，也可修改行列数、纸张和页边距
- 中文和全角标点逐格显示，可选择楷体、仿宋、宋体或黑体稿纸字体
- 数字、英文和半角符号默认两个字符占一格，可关闭
- 保留标题居中、正文两格缩进、称呼顶格、空行和落款右对齐
- 可选开启“连续标点合格”：规范建议稿会把 `（“，”）` 这类连续符号收进同一格
- 默认提供两种修正预览：
  - 同格压缩：行末标点与前一个字放在同一格
  - 整组移行：前一个字和标点一起移到下一行
- 检查标点避头尾、成对符号、两格标点、半角标点、空格、空行和文书结构
- 自动跳过网址、邮箱、小数、时间等常见例外
- 导出原样、同格压缩、整组移行三套 PNG ZIP 和三套 PDF 包
- 可直接打印某一种稿纸版本

## 发布

网站是纯静态页面，不包含构建步骤。GitHub Pages 的发布源为 `main` 分支根目录。

## 说明

- 稿纸页面用于排版参考，不直接修改原始文档。
- 扫描版 PDF 需要先做 OCR，或使用可复制的文字重新粘贴。
- 不同学校、单位和地区的稿纸规范可能不同；工具中的规则是常用规范，最终应以具体要求为准。
